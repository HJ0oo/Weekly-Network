# 통신 기초 커리큘럼 (주간 리포트 진도표)

이 파일은 매주 리포트가 **어디까지 설명했는지 기억하는 장부**다.
매주 루틴은 ① 이 파일을 읽고 ② 아직 `[ ]`인 항목 중 **가장 위 2개**를 그 주의 개념으로 삼고 ③ 리포트를 쓴 뒤 `[x]`로 바꾸고 리포트 파일명을 적는다.

## 원칙
- **순서를 건너뛰지 않는다.** 뉴스가 아무리 화려해도 뒤쪽 개념을 앞당기지 않는다.
- 아직 안 배운 개념이 뉴스 이해에 필요하면 "3문장 미리보기"로만 처리하고, 정식 설명은 순서가 올 때 한다.
- 한 주에 2개가 기본. 무거운 개념은 1개만 해도 된다. 3개 이상은 금지.

## 진도 기록 방식
`- [x] 12. RAN(무선접속망) — 2026-10-06 리포트`

## 0단계 — 전파와 신호 (통신이 물리적으로 어떻게 일어나는가)

- [ ] 1. 통신이란 무엇인가 — 정보가 먼 곳까지 가는 세 가지 방식(구리선·광섬유·전파)
- [ ] 2. 전파(전자기파)란 무엇인가 — 눈에 안 보이는 파동이 정보를 싣고 가는 원리
- [ ] 3. 주파수와 파장 — "몇 GHz 대역"이라는 말이 실제로 무슨 뜻인가
- [ ] 4. 대역폭 — 왜 대역폭이 넓으면 속도가 빨라지는가 (통신 속도의 근본)
- [ ] 5. 주파수 대역별 성질 — 낮은 주파수는 멀리 가고, 높은 주파수는 빠르지만 벽을 못 뚫는 이유
- [ ] 6. 주파수는 왜 국가가 나눠주는가 — 전파 자원과 경매, 간섭 문제
- [ ] 7. 신호 세기·잡음·SNR — "안테나 막대기 개수"가 실제로 측정하는 것
- [ ] 8. 변조 — 0과 1을 전파에 싣는 방법 (QAM까지)
- [ ] 9. 다중경로와 페이딩 — 전파가 건물에 반사되면 생기는 문제
- [ ] 10. OFDM — 4G·5G가 다중경로 문제를 푼 방식

## 1단계 — 여러 사람이 함께 쓰는 법

- [ ] 11. 다중접속 — 한 주파수를 여러 사람이 나눠 쓰는 네 가지 방법(FDMA·TDMA·CDMA·OFDMA)
- [ ] 12. 상향/하향과 이중화(FDD·TDD) — 보내기와 받기를 동시에 하는 방법
- [ ] 13. 셀(cell)과 셀룰러 구조 — 왜 기지국을 잘게 쪼개 배치하는가
- [ ] 14. 주파수 재사용과 셀 간 간섭 — 옆 기지국과 같은 주파수를 써도 되는 이유
- [ ] 15. 스케줄링 — 기지국이 1초에 수천 번 자원을 나눠주는 일

## 2단계 — 이동통신망의 구조 (RAN과 코어망)

- [ ] 16. 단말(UE)과 유심 — 내 폰이 통신망에 등록되는 과정
- [ ] 17. 기지국의 실제 구성 — 안테나, 무선 유닛(RU), 분산 유닛(DU), 중앙 유닛(CU)이 각각 하는 일
- [ ] 18. **RAN(무선접속망)** — 스마트폰과 통신사 사이 무선 구간 전체를 부르는 이름
- [ ] 19. 코어망(Core Network) — 인증·과금·인터넷 연결을 담당하는 통신망의 두뇌
- [ ] 20. 백홀과 프론트홀 — 기지국을 코어망에 잇는 유선 회선 (재난 시 최대 취약점)
- [ ] 21. 핸드오버 — 움직이는데도 통화가 끊기지 않는 이유
- [ ] 22. 네트워크가 느려지는 진짜 이유 — 혼잡, 커버리지, 백홀 중 무엇이 문제인가

## 3단계 — 세대별 기술 (2G에서 5G까지)

- [ ] 23. 1G~4G 세대 변화 — 각 세대에서 실제로 무엇이 바뀌었나
- [ ] 24. 5G의 세 가지 목표(eMBB·URLLC·mMTC)와 현실
- [ ] 25. 5G 단독모드(SA)와 비단독모드(NSA) — "진짜 5G" 논쟁의 정체
- [ ] 26. MIMO와 빔포밍 — 안테나를 여러 개 쓰면 생기는 일
- [ ] 27. 밀리미터파 — 초고속인데 왜 잘 안 쓰이는가
- [ ] 28. 와이파이와 이동통신의 차이 — 왜 둘이 따로 존재하는가
- [ ] 29. 와이파이 6·7·8 — 세대마다 무엇이 좋아졌나

## 4단계 — 망이 소프트웨어가 되다

- [ ] 30. 가상화(NFV)와 소프트웨어 정의 네트워크(SDN) — 통신 장비가 서버 위 프로그램이 되는 흐름
- [ ] 31. 네트워크 슬라이싱 — 하나의 망을 용도별로 잘라 쓰는 기술
- [ ] 32. 엣지 컴퓨팅(MEC) — 연산을 기지국 근처로 끌어오는 이유
- [ ] 33. 오픈랜(Open RAN) — 왜 기지국을 쪼개서 여러 회사 장비를 섞으려 하는가
- [ ] 34. RIC와 xApp — 기지국을 실시간으로 조종하는 소프트웨어 계층

## 5단계 — 지금 벌어지고 있는 일

- [ ] 35. AI-RAN — 기지국에 AI를 넣는다는 말의 실제 의미
- [ ] 36. AI 네이티브 네트워크와 자동 운영(closed loop) — AI가 망을 직접 고치는 구조와 그 위험
- [ ] 37. 표준화란 무엇인가 — 3GPP와 ITU가 각각 하는 일, 릴리즈(Release)의 뜻
- [ ] 38. 6G(IMT-2030) — 무엇을 목표로 하고 언제 나오는가
- [ ] 39. 위성통신과 비지상망(NTN) — 스타링크는 기존 통신망과 무엇이 다른가
- [ ] 40. 통신과 센싱의 결합(ISAC) — 전파로 통신하면서 주변을 감지하기
- [ ] 41. 시맨틱 통신 — 데이터 대신 "의미"를 보내는 통신
- [ ] 42. 통신 보안 기초 — 도청·위조 위협과 양자내성암호
